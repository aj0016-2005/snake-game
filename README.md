# Snake Game

A fun Snake arcade game built with Python and Pygame. Eat the food to grow,
earn points, and try not to hit the walls or your own tail.

## Features

- Start screen, pause screen, and game-over and win screens
- Score and best score display
- Adjustable snake speed with levels from 1 to 10
- Arrow key and WASD movement

## Requirements

- Python 3
- Pygame

Install Pygame with:

```powershell
python -m pip install -r requirements.txt
```

## Run

From this folder, run:

```powershell
python snakegame.py
```

## Controls

| Key | Action |
| --- | --- |
| Arrow keys or W / A / S / D | Move |
| `+` / `-` | Increase / decrease speed while playing |
| `P` or `Esc` | Pause or resume |
| `Q` | Quit |
| `R` or `Space` | Restart after a game |
| `M` | Return to the start screen after a game |
